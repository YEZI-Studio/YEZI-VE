# 检查项（给后面写检查脚本用）

> 能用脚本量、不是创作要点的条目；另附卡里留着、但也能量的数（标「卡里也留」）。
> 阈值都来自认可片的实测或用户的话。超了只报警、给出位置，不自动判死。

## 交付规格
| 查什么 | 阈值 | 出处 |
|---|---|---|
| 分辨率 / 帧率 | 1920×1080、60 fps | 交付规格 |
| 交付文件数 | 只交 1 个 1080p60 文件 | 系列卡 |

## 节奏、卡点、静止
| 查什么 | 阈值 | 出处 |
|---|---|---|
| 第 1 秒构图数 | ≥10 个（60 fps 下每 6 帧一格） | 系列卡 |
| 冲击帧结构 | 蓄力 2–4 帧 → 冲击 1–3 帧 → 余波 4–10 帧 | 系列卡 |
| 重击密度 | 4.6–5.3 下/秒；≥7.9 报「太碎」 | 系列卡 |
| 切点密度 | ≥3.8 个/秒，低于就报警（1.4 时档次明显下降） | 系列卡 |
| ≥1 s 的静止段 | 0 段| 全局 5 |
| 大卡点上有事件 | 大卡点那一帧有画面事件 | 全局 5 |
| 小卡点不全卡 | 不是每个 16 分音符都有顿挫 | 全局 5 |
| 纯推镜 | 只有缩放、没有画内动画的镜头 → 报警 | 全局 5 |
| 相似画面 | 连续 ≤7 s | 全局 8 |
| 同一意象 | 全片 ≤2 次 | 全局 8 |
| 主角位置 | 切点两边偏差 ≤30 px |全局 4 |

## 字
| 查什么 | 阈值 | 出处 |
|---|---|---|
| 字号 | 小标签 ≥20 px | 系列卡 |
| 屏上语言 | 全英文 | 系列卡 |

## 画面
| 查什么 | 阈值 | 出处 |
|---|---|---|
| 主色数 | 一段 ≤2 个主色 + 黑白 | 全局 10 |
| 发灰 | 暗部到不了黑、亮部到不了白 → 报警 | 全局 10 |
| 生图质检 | 没有被切了一半的素材；没有畸形的手；同一角色前后同一张脸 | 系列卡 |
| 主体被挡 | 主体被前景盖住 → 报警 | 全局 2 |

## 声音
| 查什么 | 阈值 | 出处 |
|---|---|---|
| 音乐拼接 | 中间有接点 → 报告位置（CHROMA 只报告） | 全局 9 |
| 最后一击 | 落在原曲自己的拍上 | 系列卡 |
