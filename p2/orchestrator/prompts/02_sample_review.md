## 要你做
逐镜判断能不能过，按这个顺序看：
1. 主体：镜头表写的主体有没有出现、是不是最清楚，有没有在做它的动作（不是摆着、不是只推拉）；sustain 写的「怎么撑到出画」做出来没有。
2. 进展：头 / 中 / 尾 3 帧里事情是不是单向往前走了（长出来、裂开、揭开、推到下一个位置）；切线图有锯齿、波浪，就是原地摆动 / 泵拍 / 呼吸在充数，判不过，rule 写「原地摆动充数」。是不是「大字 + 肌理」翻页；满屏噪点 / 粗颗粒在跳、一张张静图轮着换（每张只是平移）、主角不动 + 满屏叠层也不算进展。跟拍（主角钉住、世界单向流过，稀疏的前景叠层按视差走得更快）是正当的：主体最清楚、最先被看到就行，背景压暗略虚、前景绕开主体，比主体动得多不算抢主体。fix 里不许写「加微动 / 呼吸 / 轻推 / 悬浮微动，把数字拉过线」，要写主体做完什么、往哪个方向走完。删掉一个运动来源（运镜、光圈、碎片、纹理、亮线、2D 粒子、素材）时，同一条 fix 里写出替它的单向运动；不许建议「静置」「停住」「定住」「前 1/3 不动」「减少运动」（屏息那一拍、片尾海报除外）；可以说「运镜不能是唯一的动作」，不许说「不用运镜」。跟拍（主角钉住、身后的世界单向流过）是正当的动法，世界在流不算抢主体。
3. 转场：交接的东西有没有被带过去（没有就只是硬切）；有没有闪黑闪白、两镜叠在一起。
4. 颜色：是不是母题在画面里发生（主体、反光），还是整屏染色。
5. 劣质特效（判定的致命错误：简单的贴图、线段；样片定下整集的做法，这里放过去，全片都会照着做）：每个特效问它从哪来、有没有体积、亮度有没有从芯到边的衰减、和画面有没有光学关系（照亮、折射、遮挡）。手画的（2D 画布画的点、线、多边形，或同一张渲染图复制拼成物体）而且在冒充物质（碎片、粉尘、雾、烟、裂缝、气泡、水滴……），或者体积、衰减、光学关系三项里两项没有，就判不过，rule 写「劣质特效」。白名单不算：实心字、≤1.4 px 不圈主体的 HUD、≤3 帧不压主体的蓄力 / 冲击集中线、签名色的万花筒细边、展示用的空心字、整帧设计帧里的图解线和纸窗墨线框、从实拍热源喷出的短命火花、打在细节丰富的实拍上的冲击帧。fix 写出用什么真东西换（实拍、实拍叠层 SR.element、画面自己派生，配方见手册 §5b），不开刚被判劣质的同一个零件，同一处的运动不能少。
卡点准不准你判不了（图里没有声音），编排器对着音乐逐帧量；你只看冲击是不是整屏事件、闪完有没有回到旧构图（切线图上一条细横带、带的上下花纹接得上 = 闪完又回到旧构图）。
