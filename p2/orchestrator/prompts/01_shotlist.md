## 先做全片分配（写死在镜头表里；每镜由一个代理单独做，它只准用分给自己的）
常见的毛病：每镜各做各的，数字链被拆散、重复、乱序，画面没有主角，大字 + 肌理来回翻页，像 PPT。所以先由你把全片要用的东西一次分完：
- 数字链（{{NL}} 站，一站分给一镜，按顺序、不回头、不重复，每一站都要分到；一镜最多一站，没分到的镜头 number 写 ""）：
{{LADDER}}
  number 写上面的原文（数值 + 单位，照抄）。每一站绑一个真实的东西演出来（这一镜的主体），不是只把数字打在雾上。
- 大词：每镜一个 hero_word；words 是这一镜别的构图的大词。全片所有大词不重复，片名 {{SCREEN_TITLE}} 只放首尾两镜（开头海报、结尾海报，首尾循环算一次）。大词里不放数字（数字只写 number；label 可以放这一镜自己那一站）。
- 意象：image 全片同一个 ≤2 次。
- 主体：subject = 这一镜唯一的主体，一个具体的真东西；subject_src = {kind, file, gen, request_id}：
  · kind "实拍"：file 写下面清单里的名字（如 "F07"）；清单里没有的写 request_id（见 footage_wish）。一段素材全片只当一次主体；
  · kind "生图"：清单里有现成的图才写 file；没有就写 gen（给生图模型的一句话：主体、材质、光、构图），交给这一镜的制作代理——生图通道在不在、怎么生成见上面「制作环境」的生图那一行。能用实拍就别选生图。
  大字、雾、烟、粒子、纹理这类肌理不算主体（这样做就丢了主角）。
- action：主体在这一镜做的一个动作（具体的动词：砸下、裂开、旋入、升起、炸成碎片……；「展示」「推近」「飞入」只写运镜或字出场的不算），从头到尾一路往前推进。action 和 event 里不写往静里收的词：「停稳」「定住」「归零」「几乎不动」「越来越慢」「悬着」「停住」「原地转」（编排器会拦下发回重排；数字落到 0 也写成动作，如「读数砸到 0」）。只有屏息那一拍、片尾海报可以静。
- sustain：这一镜怎么撑到出画，四选一：分批揭示 / 运镜跟着主体 / 东西在干活 / 动作接力（切得快不等于在动：每个构图里都要有一件事往前走一步；原地摆、呼吸、来回推拉不算）。
- type_fx：这一镜大字的字效 {font, entry, layout}：font 从系列定稿字体里选（{{FONTS}}），entry = 出场方式（SLAM 砸入、逐字母、被冲击帧打出……），layout = 版式（出血裁切、半屏对撞、居中定版……）。同一种字效（三样完全一样）连着最多 2 镜，第 3 镜至少换一样。
- 交接（每个切点）：transition_in.handoff = {out, at, in}：out = 上一镜出画的东西，at = 方向 / 位置（如「从右往左甩出」「画面正中，同一大小」），in = 这一镜入画的东西；kind 要能把 out「带过去」变成 in。s01 写片尾怎么接回第 0 帧。

## 要你做
先在镜头表顶上写三项：
- route：转场路线，连续（一镜到底）/ 蒙太奇 / 混合，三选一
- signature：{shot, why}：全片 1 个即梦、可灵做不出来的签名镜头（哪一镜、为什么做不出来）
- deviations（可选）：[{id, why}]：故意偏离规则里「默认」档的地方，id 写规则 id（如 root.transition.param1），why 一句理由
再把全片切成 6–16 个镜头，每个镜头 1–2 小节（开头那一镜是钩子，只给 1 小节），一次独立写代码。一镜只有一个主体：排长了，代理只能对着同一个东西换角度原地耗（例如开头一镜排了 3 小节，5 秒都是同一个主角物），所以宁可多切几镜换主体。每个镜头：
- id："s01" 起编号；section：属于哪个段落（S1…）
- bars：[起始小节, 结束小节(不含)]，整数小节号：镜头边界落在小节线上（小节中间换画面用 cut_every 的切点），镜头首尾相接、铺满全片
- cut_every：镜头内切点的密度档 "16th" | "8th" | "beat" | "half" | "bar" | "none"（60 fps 下 16 分音符 ≈ {{SIXTEENTH_F}} 帧）。切点由编排器从音乐起音里取，不再按格均分：16th = 本镜所有有起音的 16 分音符（起音按本镜自己的轻重算，前奏的弱起音也算）；8th = 重音 + 8 分位置上有起音的格；beat = 只切重音；half = 每 2 拍最强的重音；bar = 每小节最强的一下。没有起音的地方不会有切点。整片切点密度照原片：每秒 3–5 刀（点火 3.8、Light 5.3），前奏也一样快切（原片前 4 小节照样每秒 3–5 刀，靠快切和字把人拽住，不是慢慢攒）；开头那一镜是钩子，用 "16th"（原片第 1 秒 7–9 个构图）。只有屏息那一拍、最后海报那一镜可以少切或 "none"。编排器会按这首歌能给的密度核，太稀会发回重排。切点多不等于好：每个切点都要真的换构图、换来新东西（新素材、新景别 / 机位、新字、揭示下一层、主体动作的下一步），不许在切点上对同一张图宽紧来回切、对同一主体左右来回摆；主角钉住时，钉住只管切点前后那两帧（位置、大小不跳），格内主体或机位可以一路推近 / 横移，过了切点接着走，不回到原来的大小；计划切点上换的是主体周围占画面大头的东西（换一条素材或素材时段、换色块底、换世界层），纯色底上钉住的主角切不出来（切点前后两帧几乎同图）。一镜只有一条实拍时，切点之间换景别 / 机位（一路往前推进，不回到用过的构图）、换素材时段、实拍和白底大字设计帧 / 色块字卡交替，不要降档；跟拍主角的镜头在切点上换它身后的世界层（aux_footage 里轮换），主角不跳
- holds：[[小节,拍],…] 这一拍里不切（屏息那一拍、drop 后一拍编排器会自动加）
- look："design"（白底大字设计帧）| "footage"（画面大头是实拍：满屏实拍，或者主角站在流动的实拍世界前跟拍）；设计帧和实拍交替。镜头里的运动大半来自实拍素材自己在动、每个切点换进新画面并大幅落地
- subject、subject_src、action、sustain、type_fx、hero_word、words、number：见上面的全片分配
- label：小标签（{{TEXT_LANG}}）；label_px：小标签字号（≥20）
- event：这一镜的动画事件（不是静图加推拉）；cut_every 不是 "none" 的，写清每个切点换来什么。顺带写清这一镜的运动从哪来（可以几样叠着用）：素材自己在动（看清单里的「自带运动量」，慢素材配 2–3 倍变速）、每个切点换进新画面并落地（砸入、甩、推穿）、跟拍（主角钉住、有纹理的世界单向流过）、主体动作往前走、实拍叠层（这一集叠层表里的黑底元素）单向飘 / 迎面推、字砸入再被推走；运镜可以用，但不当唯一的动作。碎、裂、雾、烟这类特效写明从哪来：哪条实拍（F 号）、哪种实拍叠层——不用 2D 画的点、线、多边形冒充（用简单的贴图、线段做特效是致命错误）；清单和叠层表里没有的真材料写进 footage_wish。跟拍主角的镜头（片尾海报除外）的 event 写明每个计划切点换掉的是哪一层（世界层换哪条素材或哪个时段、换色块底、换字），主角物不跳
- image：意象标签
{{TRANSITIONS}}
  每个 transition_in 再加 handoff（见上）。
- parts：用到的零件名，照上面「零件」清单写（每镜至少 2 个会动的：冲击、转场、万花筒、运镜、跟拍、主角字、叠层（实拍元素叠加）、碎裂（画面碎开）；主角叠在流动世界上的镜头带 track）。HUD 不算会动的零件，2D 粒子不再用
- footage：这一镜的世界层 / 背景用哪条实拍（写清单里的名字）。跟拍主角的镜头（片尾海报除外）必须写 footage 或 aux_footage：主角叠在这条实拍上跟拍。配纯色底、程序画的底，镜头里就只剩画出来的纹理在动。只有 design 镜头和片尾海报可以写 "none"
- aux_footage（可选）：[清单里的名字, …]，2–4 条，这一镜切点上轮换的辅助世界层 / 背景（不算主体，主体素材照旧一段只当一次主体）；一条实拍撑不起这一镜的切点、或者是跟拍主角的镜头时写
- footage_wish（可选）：[{"need": "黑底上升的气泡，慢动作", "use": "overlay", "seconds": 4, "why": "…", "query": "bubbles rising black background"}]，这一镜想要、清单里没有的真材料（use：overlay 黑底元素叠层 / world 世界层 / subject 主体；query 写英文搜索词：画面里的东西本身，3–5 个词，主体名词或型号在前，不写数值、单位和 footage、moving、high speed 这类泛词）。缺素材不用降方案：编排器去 Pexels、Wikimedia Commons 这些免费素材站找、下、入库（overlay 自动烘焙成叠层），制作代理拿到的素材表里会标出来。拿它当主体、世界层、辅助素材的，给它一个 request_id（全集唯一，REQ_ 开头），subject_src.request_id / footage / aux_footage 写这个 id：镜头表通过后编排器先找这些，找到就把 id 换成 F 号，进制作前给你看一次联系表确认
